## 约定

- 规划文档只写目标与步骤，不把未完成的写成现状；实现后更新为事实或归档。
- 与代码冲突时以代码为准，并就地修正文档。
- 新增规划文档必须登记到 [文档索引](../README.md)；未登记的文件会被 `bun run check:docs` 拦下。
- 规划里的路径、命令、字段名必须能在仓库或下游项目中找到对应物，不写臆测的 API。
