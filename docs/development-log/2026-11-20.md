## Decisions

- `dev stop` stays out of this change. devkit does not own the system Postgres instance and SILO exposes no pid; a safe implementation needs pid files written at spawn time plus an ownership check.
- Containerizing the stack is out of scope. The package keeps the "use the tools already installed" contract until a third consumer proves otherwise.
- `applyOnlineEnv` keeps its fixed cleanup list. `S3_*` credentials belong to the host because they may address R2 rather than local MinIO.
- Only `dev` becomes optional in `defineDevkit`; splitting `database` / `storage` into per-entry configs would be a public API redesign.
