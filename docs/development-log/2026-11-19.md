## Decisions

- Package shape: a publishable package in its own repository (single package plus subpath exports), not a copied template, and not merged into `starter-ts-lib`.
- Guides live in the same repository and version; downstream docs keep only project-specific parameters and troubleshooting.
- The proxy stays Bun-only; `pg` and `drizzle-orm` are optional peers so downstream versions are not coupled.
- The pure `./shared` entry may be imported by Workers; every other entry is off-limits there.
- The whole project (source, public docs, internal docs) is written in English to avoid translation drift.

## Findings

- `yumemita-stream-dashboard/scripts/lib/dev-services.ts` still spawns `scripts/dev-db-proxy.ts`, which was renamed to `scripts/commands/dev/proxy.ts` in `02d45f7`. When the proxy is not running, `bun run dev` waits about ten seconds for the health check and then fails. Tracked as S0-1.
- Existing tsdown defaults emitted `.mjs` / `.d.mts` and dropped the `bin/` path for the executable entry; both are now fixed with explicit entry maps and `outExtensions`.
