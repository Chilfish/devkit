# Security policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Report privately through GitHub Security Advisories:

<https://github.com/Chilfish/devkit/security/advisories/new>

Do not open a public issue and do not disclose exploit details in a PR.

Include:

- Affected versions
- Reproduction steps or a minimal reproduction repository
- Impact and potential exploitation
- Suggested fix direction (optional)

## Response

- Confirm the reproduction and assess impact after receiving the report.
- Ship the fix as a patch release and describe the scope in the CHANGELOG.
- Record the incident per [postmortem](./docs/postmortem/README.md).

See [docs/engineering/security.md](./docs/engineering/security.md) for details.
